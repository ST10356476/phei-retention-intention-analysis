# Data

The survey data is **not included** in this repository.

## Why
Participation was voluntary and anonymous. Under the study's ethical clearance and the Protection of Personal Information Act 4 of 2013 (POPIA), the data is stored only by the researcher.

## Expected file
To run the notebook, put the survey export in this folder:

data/Determinants_of_Student_Retention_in_Private_Higher_Education_Institutions_In_South_Africa1-120.xlsx

- **Source:** online questionnaire, collected 15 September – 2 November 2026
- **Records:** 120 (119 consented; 1 declined)
- **Format:** Excel export, one row per respondent

## Variables
| Section | Items | Description |
|---|---|---|
| Consent | 1 | Agree / decline to participate |
| A | A1–A7 | Age, gender, province, year of study, qualification, employment, funding |
| B | B1–B12 | Institutional factors |
| C | C1–C8 | Academic engagement |
| D | D1–D10 | Student satisfaction |
| E | E1–E5 | Retention intention (E3 and E4 reverse-scored) |

All items in Sections B–E use a 5-point Likert scale (1 = Strongly Disagree, 5 = Strongly Agree).

To request access to the data for academic purposes, contact the researcher.
